> **普通的魔法使，来到了主人的电脑桌面上！★**  
> 本项目是基于 **PyQt6** 物理动画引擎与 **MaiBot** 智能内核深度融合重构的魔改版桌面宠物与本地助理系统。不仅具备可爱的 Shimeji 桌面交互表现，更能一步到位操控本地 Windows 系统与网易云音乐，并与 QQ 端打通实现“双端同脑、跨端记忆”。

---

## 🌟 核心特性与架构升级

### 1. 架构合二为一：去中介化本地执行（一步到位）
- **旧架构**：`MaiBot 大脑 -> 网络/WebSocket 转发 -> 桌面客户端解析 -> Windows API`（多跳链路，受客户端生命周期制约）。
- **新架构**：MaiBot 作为系统级主控，**原生直连 Windows API 与系统协议**。音乐播放、切歌、音量调节、锁定屏幕、剪贴板读取直接在后台秒级执行，并通过双工通道通知桌宠进行气泡与动作呈现。

### 2. 纯粹的表现层：PyQt6 桌面交互
- **54 帧经典 Shimeji 动画**：包含走动、跳跃、爬墙、悬挂窗体、翻跟头、看鼠标、坐立发呆等多种物理状态。
- **物理与交互引擎**：重力下落碰撞检测、鼠标拖拽抛掷、窗体边缘吸附与漫步。
- **生动的对话呈现**：漫画风自适应气泡、打字机逐字展开、Edge-TTS 自然女声语音伴读。

### 3. 一键全包与运行环境统一
- **统一虚拟环境 (`.venv`)**：桌宠与 MaiBot 完全整合在统一的 Python 3.13 运行环境中，使用 `uv` 统一管理全部依赖，无需在系统全局重复安装包。
- **一键幂等拉起**：提供 `启动一体化.bat` / `start_all.ps1`，自动串联 NapCat（QQ 协议端）-> MaiBot 大脑 -> 桌宠 GUI，智能检测端口与进程状态，防重复启动。

### 4. 强大的桌面原生能力
- 🎵 **网易云原生直控**：动态读取注册表修正 `orpheus://` 协议，无缝拉起网易云客户端播放指定歌名、每日推荐、我喜欢的音乐等。
- 💻 **电脑系统操控**：系统开机时长统计、瞬时锁屏、全局音量调节、打开常用软件或网址。
- 📷 **多模态视觉与截图**：基于 Pillow/mss 截屏能力，支持 QQ 远端查看当前电脑屏幕或本地多模态视像理解。
- ⏳ **贴心提醒与日程**：支持自然语言定时提醒（如“30分钟后提醒喝水”）。

## 🚀 快速启动指南

### 运行环境要求
- **操作系统**：Windows 10 / 11 (x64)
- **运行环境**：已配置好 MaiBot 及其统一虚拟环境（位于 `D:\MaiBot-1.2.4\.venv`）

### 一键启动
双击项目根目录下的 **`启动一体化.bat`**：
```cmd
启动一体化.bat
```
脚本将按序完成：
1. 校验并唤起 NapCat QQ 协议壳（端口 `3001` / `6099`）；
2. 自动对齐桌宠与 MaiBot 的 DeepSeek / 视觉模型配置；
3. 启动 MaiBot 大脑服务（WebUI: `http://127.0.0.1:8001`）；
4. 自动拉起魔理沙桌宠 GUI 客户端（网关 `ws://127.0.0.1:8400`）。

## 🎮 使用与交互指令

### 桌面端直接交互
- **鼠标左键拖拽**：抓起魔理沙抛向空中，体验自由落体。
- **鼠标双击**：唤起聊天输入框，可与魔理沙直接对话或输入斜杠指令。
- **鼠标右键**：弹出快捷功能菜单（音乐控制、视像巡检、羁绊查看、魔法设置等）。
- **全局快捷键**：默认 `Ctrl + Alt + M` 快速呼出输入框。

### 常用斜杠指令大全
| 指令 | 说明 |
|---|---|
| `/help` | 查看全量指令帮助列表 |
| `/点歌 <歌名>` | 在本机网易云音乐搜索并播放指定歌曲 |
| `/推荐歌曲` | 播放今日魔理推荐歌单 |
| `/播放` / `/暂停` / `/下一首` | 控制当前音乐播放与切歌 |
| `/音量 <大\|小\|静音>` | 调节 Windows 系统主音量 |
| `/开软件 <软件名/网址>` | 快速启动本机应用程序或打开网页 |
| `/开机时长` | 查询电脑连续运行时间 |
| `/锁屏` | 立即锁定当前工作站 |
| `/好感度` | 查询魔理沙与主人的羁绊等级（双端同源） |
| `/天气 <城市>` | 查询指定城市实时天气情况 |
| `/提醒 <分钟数> <内容>` | 设置定时桌面通知 |
